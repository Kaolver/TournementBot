# TournamentBot

A Discord tournament bot for Null Rush, integrating with [Challonge](https://challonge.com).

## Commands

- `/tournament post url:<link>`: Read the bracket and post the sign-up panel.
- `/tournament sync`: Manually trigger a bracket sync.
- `/tournament settings`: Configure admin role, timezone, agree-a-time deadline, and venue.
- `/tournament board`: Display tournament status, scheduling progress, and API budget.
- `/tournament entrants`: View registered entrants and bracket linkage status.
- `/tournament repost`: Re-post the registration panel in the channel.
